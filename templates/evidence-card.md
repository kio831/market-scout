# Evidence Card 模板（v1.1）

> 每条重要市场证据填一张。字段语义与证据类型、置信度口径见 `references/evidence-chain.md`。
> 铁律：无来源只能标"假设"；禁止把证据"能证明"的范围夸大到它证明不了的事。

---

## 证据卡片

**Evidence（证据原文）**：<尽量引用原文，不转述变形>

**Source（来源）**：<链接 / 截图 / 访谈记录 / 观察记录；无来源写"无"→ 只能算假设>

**Evidence Type（证据类型）**：<直接引用 / 截图 / 搜索命中 / 官方页面 / 现实观察 / 访谈记录 / 推断 / 假设>

**Confidence（置信度）**：<高 / 中 / 低>

**What this evidence proves（证明了什么）**：<收窄到字面可支持的结论>

**What this evidence does NOT prove（不能证明什么）**：<明确写出它证明不了的更强结论，防过度解读>

**Date（采集日期）**：<YYYY-MM-DD>

**所属 Opportunity ID（可选）**：<MS-###>

---

### 示例（示意，非真实数据）

- **Evidence**：某用户在论坛称"我每周花 3 小时清理 CSV"。
- **Source**：某论坛帖（示意 URL）。
- **Evidence Type**：直接引用。
- **Confidence**：高（一手原文，来源可溯）。
- **Proves**：至少存在 1 个用户每周花约 3 小时处理 CSV。
- **Does NOT prove**：不能证明"大量企业用户都有此痛点"，不能证明"愿意付费"。
- **Date**：2026-09-02
