# Problem Card 模板（v1.1）

> 每捕获一个候选问题填一张。字段语义见 `references/problem-framework.md`。
> 证据等级、来源、证据链摘要必填；无来源只能标 C。证据链规则见 `references/evidence-chain.md`。

---

## 问题卡片

**Opportunity ID（可选，升级后分配）**：<MS-###>

**问题**：<一句话描述核心痛点>

**用户**：<具体画像，含数量级；不写"所有人">

**场景**：<在什么流程/环节/时刻发生>

**频率**：<每天/每周/每月几次？标注是观察还是估计>

**痛苦**：<时间/成本/风险/情绪损失，尽量量化>

**当前解决方式**：<人工 / Excel / 外包 / 免费工具 / 将就>

**为什么不满意**：<慢？贵？易错？没人手？要学？>

**潜在损失**：<不解决会怎样：钱 / 时间 / 客户 / 合规>

**付费信号**：<有则写来源；无则写"暂无">

**AI 可能介入的环节**：<具体到流程步骤，不写"全程自动化">

**需要验证的问题**：<下一步要证实什么假设，如"是否愿意每月付 XX 元？">

**证据等级**：A（已验证） / B（潜在） / C（假设）

**来源**：<搜索链接 / 评论原文 / 现实观察记录；无来源标"待搜索">
