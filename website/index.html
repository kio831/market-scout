v3.0.0 · Decision Layer

V3 新增决策层，V2 能力全部保留

V3 在 V2 五阶段流水线之上新增决策层：证据三态 → 机会评分 → 三档决策 → MVP → 行动计划。V2 的需求验证、项目评估、机会转项目、商业化获客全部保留为分析引擎。

Market Evidence

01 · 市场证据

  • 每个关键结论强制三态：Evidence / Inference / Unknown
  • 证据充分度三级；Unknown 按 0 计，不编造、不虚高
  • 证据不足直接熔断，说明缺什么、去哪补
Opportunity Score

02 · 机会评分 0-100

  • 7 维加权：需求 15 · 痛点 15 · 竞争切入 15 · 变现 20 · 开发 15 · 获客 10 · AI 优势 10
  • 计算式必须可手工复算，每分绑定证据
  • 竞争维度评"切入空间"，禁止"竞品少=高分"
  • 7 条致命红旗一票否决
Decision

03 · 三档决策

  • 🟢 RECOMMENDED 值得继续做
  • 🟡 POTENTIAL 有机会但需先验证
  • 🔴 NOT_RECOMMENDED 不建议投入
  • 每条结论强制编号 Why，绑定证据
MVP Blueprint

04 · MVP 方案

  • 9 字段：定位 / 用户 / 问题 / 价值 / Must≤3 / 以后再做 / 不做 / 难度 / 技术栈
  • 只回答"一个人最快怎么验证这个想法"
  • 默认 L1 人工+AI 先卖结果，再产品化
Action Plan

05 · 行动计划

  • 按机会类型动态生成（企业工具 / 个人工具 / AI Agent / 本地服务 / 数字产品）
  • 每步 5 要素：目标 / 做什么 / 成功标准 / 失败转向
  • 结尾必有"今天做什么" + 第一笔钱路径
V2 Engine（保留）

V2 分析引擎，全部保留

  • 需求验证（6 信号 + JTBD 付费理由链）
  • 项目评估（7 维加权 + 三档 GO / VALIDATE_FIRST / NO_GO）
  • 机会转项目（Level 1-5 + MoSCoW + MVP 五项）
  • 商业化获客（定价锚 + 首批 10 客户 + GTM 三阶段）
  • 三类搜索、证据链、状态机、停止机制

三档结论，明确不模糊

不是"看起来不错"，而是有阈值、有红旗、有下一步的明确判断。

🟢

值得继续做 RECOMMENDED

综合分 ≥75 + 需求/痛点/变现门槛全过 + 无致命红旗。可以投入，按 MVP 与行动计划推进。

🟡

有机会但需先验证 POTENTIAL

分数够或差一点，但付费等关键假设未证实。先做最小验证实验，达标转 🟢，不达标转 🔴。

🔴

不建议投入 NOT_RECOMMENDED

综合分 <55 或触发致命红旗。给出停止原因、导致停止的证据、以及什么新证据可重启。

How It Works

从想法到第一笔钱的完整工作流

V2 五阶段流水线照常跑通，V3 决策层把分析压缩成"值不值得做 + 今天先做什么"的结论。伪需求和 NOT_RECOMMENDED 会在对应阶段熔断，不硬造机会。

1

FIND发现机会

用户输入一个想法/现象/视频/评论区 → 三类搜索（Problem/Solution/Payment）→ 证据链五段式 → Problem/Evidence Card → 8 维粗评分。只有 Problem 无 Payment 时不得判为强商业机会。

2

VALIDATE需求验证

痛点 → 三层用户 → 需求强度 6 信号 → 替代成本 → 付费理由链 JTBD 5 环。结论三选一：真实需求已验证 / 需求存在但付费未验证 / 伪·弱需求。伪/弱需求在此熔断。

3

EVALUATE项目评估

7 维加权打分（需求强度直接继承，不重打）→ 综合分 0-100（计算式可复算）→ 7 条红旗检查 → 三档结论 🟢/🟡/🔴。NO_GO 在此熔断，给出停止原因与重启条件。

4

BLUEPRINT机会转项目

推荐产品形态（默认 L1 人工+AI 先卖结果）→ MoSCoW 核心功能（M≤3）→ MVP 五项 → 技术方向 → 最小验证实验 → 差异化切入点落地。没有真实付费用户前不跳到 L4/L5。

5

MONETIZE商业化与获客

付费方/ICP → Offer 三档 → 商业模式 → 可解释定价 → 首批 10 客户获取 → 主渠道（≤2）→ GTM 三阶段 → 第一笔钱计划。当前不实现支付/订阅/会员，只产出方案与验证动作。

📄

REPORT机会报告

五阶段汇总为最终 Opportunity Report，结论先行：10 秒看懂"在分析什么 → 得到了什么 → 下一步做什么"。含目录、每阶段小结、行动路线（今天/本周/2-4 周）、最终判定。

V3

DECIDE决策层（v3.0.0 新增）

Evidence/Inference/Unknown 证据三态 → Opportunity Score 7 维 0-100（可复算）→ Decision 三档（值得继续做 / 有机会但需先验证 / 不建议投入）→ MVP Blueprint 九字段 → 按机会类型动态生成 Action Plan。V2 五阶段照常复用为分析引擎。

Quick Start

安装后，直接说一句话就能用

把 market-scout-v3.0.0.zip（或 .skill）拖入支持 Skill 的 AI 客户端，或解压后把 market-scout/ 文件夹放入技能目录。验证：打开 SKILL.md 能搜到 Opportunity Score 和 值得继续做 RECOMMENDED 即为 v3.0.0。

你想做什么示例触发词
快速判断一个想法"学校打印店总有人让老板改 PDF，有没有机会？"
验证需求真假"这个需求是真的吗？用户真的愿意要吗？"

机会转成项目"帮我把这个想法做成 MVP，第一版做什么？"
设计怎么赚钱"怎么收费？定什么价？商业模式怎么设计？"
找第一批客户"第一批用户/客户从哪来？怎么获客？"
完整分析"从发现到商业化帮我完整分析一遍，出一份机会报告"
准备开干"帮我拿第一单" / "我准备做了"
